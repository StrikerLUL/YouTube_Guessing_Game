> **The ultimate anime guessing challenge!** Identify your favorite series from their openings and endings - now with improved UI and robust video support! 🎧

---

## ✨ Features

### 🎮 Game Modes
- **🎧 Audio-Only Mode**: The ultimate challenge! Video is completely hidden. Guess the anime solely by its music.
- **🎬 Video Mode with Blur**: Adjustable blur intensity (0-30px). See a fuzzy outline or just colors while listening.
- **⚙️ Configurable**: Admins can switch modes and adjust difficulty on the fly.

### 🎨 Modern Design
- **Refined UI**: Clean, modern interface with a professional color palette.
- **Responsive Layout**: Works great on both desktop and mobile devices.
- **Micro-Interactions**: Pulse animations, smooth transitions, and intuitive feedback.
- **Typography**: Uses 'Inter' Google Font for a crisp, readable look.

### 🕹️ Gameplay
- **⏱️ Timer System**: 30-second countdown for each round. Can you guess fast enough?
- **⚡ Speed Bonus**: Earn more points by guessing quickly!
- **⏭️ Skip Button**: Stuck? Skip the current anime and move to the next.
- **🏆 High Scores**: Compete against yourself with the built-in local leaderboard.
- **✨ Visual Effects**: Confetti on wins and a shake effect on misses for better feedback.
- **Smart Autocomplete**: Type and get instant suggestions without any clipping issues.
- **Robust Video Support**: Improved YouTube link recognition, including Shorts and mobile links.
- **Hint System**: Stuck? Reveal up to 3 hints to help you guess.
- **Score Tracking**: Keep track of your streak, accuracy, and total score.

## 🚀 Quick Start

1.  **Download**: Clone the repository or download `index.html`.
2.  **Run**: Simply open `index.html` in any modern web browser. No server or installation required!
3.  **Play**: Click "🎵 START AUDIO" and test your anime knowledge!

## 🛠️ Technology Stack

- **HTML5 & CSS3**: Modern features including Flexbox, Grid, and CSS Variables.
- **Vanilla JavaScript**: Fast, lightweight, and dependency-free.
- **LocalStorage**: Persistent data without a backend.
- **YouTube IFrame API**: Seamless video and audio integration.
